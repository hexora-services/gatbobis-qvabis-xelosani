გამოქვეყნება GitHub Pages-ზე:
1. შექმენით ახალი PUBLIC GitHub Repository (არ შეცვალოთ არსებული Thermohut ან სხვა პროექტი).
2. ZIP-იდან ამოიღეთ ყველა ფაილი და ატვირთეთ რეპოზიტორიის ძირითად (root) საქაღალდეში.
   GitHub-ის „Upload files“-ში თავად ZIP ფაილის ატვირთვა არ გამოდგება — საჭიროა მისი შიგთავსი.
3. შედით Settings > Pages > Build and deployment > Deploy from a branch.
   აირჩიეთ main / (root), შემდეგ Save.
4. საიტის გახსნის შემდეგ გადაამოწმეთ მობილურიდან ზარის ღილაკი.

მნიშვნელოვანი SEO ნაბიჯები გამოქვეყნების შემდეგ:
1. როცა უკვე გეცოდინებათ რეალური საიტის სრული მისამართი, index.html-ის <head>-ში
   დაამატეთ canonical და og:url (მხოლოდ ნამდვილი მისამართით):
   <link rel="canonical" href="https://example.ge/">
   <meta property="og:url" content="https://example.ge/">
   (https://example.ge/ მხოლოდ მაგალითია; ჩაანაცვლეთ თქვენით.)
2. სურვილისამებრ შექმენით sitemap.xml, რომლის <loc> შეიცავს ზუსტად ამ URL-ს, და
   robots.txt ფაილში მიუთითეთ Sitemap: https://თქვენი-დომენი/sitemap.xml
3. დაამატეთ Google Search Console-ში საიტი: https://search.google.com/search-console/
   გადაამოწმეთ მფლობელობა; URL Inspection-ით მოითხოვეთ ინდექსაცია.

5. შეაგროვეთ მხოლოდ რეალური მომხმარებლების შეფასებები, გადაიღეთ სამუშაოს რეალური ფოტოები.
